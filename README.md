# 香港 iPhone 專業維修中心網站專案 (v2)

本專案為 iPhone 維修店舖之網頁設計範本（包含 4 個頁面與 CSS 樣式）。

## 檔案結構
- `index.html` : Webpage 1（主頁 / 主視覺區）
- `services.html` : Webpage 2（服務目錄與關鍵字說明）
- `gallery.html` : Webpage 3（維修照片展示區 - 已更新移除影片區塊）
- `contact.html` : Webpage 4（最新活動與聯絡資料）
- `style.css` : 全站樣式檔
- `images/` : 圖片素材資料夾
- `videos/` : 影片素材資料夾
