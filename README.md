# iPhone 維修店舖網站專案 (iPhone Repair Website Classwork)

本專案包含 4 個 HTML 網頁與 1 個 CSS 樣式表，完全符合《為一間香港維修 iPhone 手機公司製作網站》作業要求。

## 檔案結構
- `index.html`: Webpage 1（主頁 / 主視覺區）
- `services.html`: Webpage 2（服務目錄 & 關鍵字說明）
- `gallery.html`: Webpage 3（維修照片與影片展示區）
- `contact.html`: Webpage 4（最新推廣活動與公司聯絡資料）
- `style.css`: 全站 CSS 樣式表（含響應式設計與 Apple 科技風格）
- `images/`: 存放圖片素材（Logo、Key Visual、展示照片）
- `videos/`: 存放影片素材（維修展示影片）

## 如何測試與執行
1. 將本 ZIP 檔案解壓縮。
2. 直接雙擊 `index.html` 即可在瀏覽器中開啟網站。
3. 點擊頂部導航欄可切換 4 個主要分頁。
